# PRD: 인플루언서 광고 단가 계산 앱

## 1. 제품 개요

인플루언서의 팔로워 수, 최근 콘텐츠 성과, 카테고리 적합성, 캠페인 조건을 바탕으로 광고 협업의 권장 단가를 산출하는 웹 애플리케이션이다. 브랜드·대행사는 빠르고 일관된 예산 수립을, 인플루언서는 근거 있는 견적 제시를 할 수 있어야 한다.

## 2. 문제와 목표

광고 단가는 팔로워 수만으로 정해지기 어렵다. 플랫폼, 실제 도달·참여 성과, 콘텐츠 유형, 카테고리, 사용권 및 독점 조건 등이 함께 영향을 주지만 이를 한 번에 비교할 기준이 부족하다.

### 목표

- 캠페인 입력 후 권장 단가와 합리적인 범위를 1분 안에 제공한다.
- 산정에 사용된 지표와 각 가중치를 보여 주어 결과를 설명 가능하게 한다.
- 플랫폼과 콘텐츠 포맷별 단가 차이를 반영한다.
- 계산 결과를 저장·공유 가능한 견적서로 만든다.

### 성공 지표

- 견적 계산 완료율 80% 이상
- 계산 시작부터 결과 확인까지의 중앙 소요 시간 60초 이하
- 저장된 견적의 공유 또는 내보내기 비율 30% 이상
- 사용자 평가 기준 단가 결과 신뢰도 4/5 이상

## 3. 사용자

| 사용자 | 주요 목적 | 대상사용자가 중요함.
| --- | --- |
| 브랜드 마케터 | 캠페인 예산을 빠르게 추정하고 후보 인플루언서를 비교한다. |
| 광고 대행사 AE | 클라이언트용 견적의 근거를 만들고 협업 조건을 반영한다. |
| 인플루언서/매니저 | 콘텐츠와 성과에 맞는 제안 단가를 산출한다. |
| 관리자 | 기준 단가와 가중치를 관리하고 서비스 사용 현황을 확인한다. |

## 4. 핵심 사용자 흐름

1. 사용자가 플랫폼, 인플루언서 지표, 콘텐츠 유형, 캠페인 조건을 입력한다.
2. 앱은 지표 검증 후 권장 단가, 최저·최고 범위, 산정 근거를 보여 준다.
3. 사용자는 보정값을 조정해 시나리오를 비교한다.
4. 결과를 견적서로 저장하고 링크 또는 PDF로 공유한다.

## 5. 기능 요구사항

### 5.1 단가 계산기 (MVP)

- 지원 플랫폼: Instagram, YouTube, TikTok.
- 입력 항목
  - 팔로워/구독자 수
  - 최근 30일 평균 조회 수(선택), 평균 좋아요·댓글·공유 수
  - 참여율(자동 계산 또는 직접 입력)
  - 카테고리(패션, 뷰티, 푸드, 게임, IT, 육아 등)
  - 콘텐츠 형식(피드, 릴스/숏폼, 스토리, 유튜브 영상, 라이브)
  - 제작 수량 및 게시 기간
  - 광고 활용권 기간, 경쟁사 독점 기간, 긴급 제작 여부
- 출력 항목
  - 권장 단가와 최저·기준·최고 단가 범위 (KRW)
  - 예상 도달·참여 지표
  - 단가에 영향을 준 요인별 설명
  - 입력값 또는 보정값 변경에 따른 실시간 재계산

### 5.2 견적 관리

- 계산 결과를 견적서로 저장, 복제, 수정, 삭제한다.
- 견적서에 브랜드명, 캠페인명, 유효기간, 메모를 기록한다.
- 읽기 전용 공유 링크와 PDF 내보내기를 제공한다.
- 견적별 상태: 초안, 발송됨, 수락됨, 거절됨.

### 5.3 비교와 관리자 기능

- 저장한 여러 인플루언서 또는 견적을 표로 비교한다.
- 관리자는 플랫폼·카테고리·포맷별 기준 단가와 가중치를 수정한다.
- 가중치 변경 이력과 적용 시작일을 보관한다.

## 6. 단가 산정 모델

초기 버전은 설명 가능한 규칙 기반 모델을 사용한다. 기준 데이터가 축적되면 예측 모델을 보조적으로 도입한다.

```text
기준 단가 = 플랫폼별 CPM 기준값 × 예상 도달 수 / 1,000
최종 단가 = 기준 단가
          × 참여율 보정계수
          × 카테고리 보정계수
          × 콘텐츠 포맷 보정계수
          × 인기도 보정계수
          + 제작 추가비
          + 활용권 비용
          + 독점 비용
          + 긴급 제작 비용
```

- 예상 도달 수는 평균 조회 수를 우선 사용하고, 없으면 팔로워 수와 플랫폼별 도달률로 추정한다.
- 참여율은 `(좋아요 + 댓글 + 공유) / 팔로워 수`를 기본값으로 하되 플랫폼별 정의를 적용한다.
- 인기도 보정계수는 최근 성과 추세, 조회 수 대비 팔로워 비율, 캠페인 적합성으로 계산한다.
- 결과는 기준 단가의 70~130% 범위로 제시한다. 범위와 모든 보정값은 운영자가 설정 가능해야 한다.
- 알고리즘은 개인의 민감한 특성(성별, 인종 등)을 단가 변수로 사용하지 않는다.

## 7. 화면 요구사항

| 화면 | 주요 구성 |
| --- | --- |
| 대시보드 | 최근 견적, 새 견적 만들기, 월별 계산 현황 |
| 새 견적 | 단계형 입력 폼, 입력 검증, 실시간 요약 |
| 계산 결과 | 권장 단가 범위, 요인별 기여도, 시나리오 조정, 저장/공유 |
| 견적 상세 | 캠페인 정보, 산정 스냅샷, 상태 변경, PDF 내보내기 |
| 비교 | 인플루언서별 성과·단가·CPM 비교 |
| 관리자 | 기준값·가중치·카테고리 관리 및 변경 이력 |

## 8. 데이터 모델

- `User`: 계정, 역할, 조직 ID
- `Organization`: 조직명, 요금제, 기본 통화
- `InfluencerProfile`: 플랫폼, 채널 URL, 팔로워 수, 카테고리, 성과 지표, 갱신일
- `Campaign`: 브랜드, 목표, 기간, 타깃 카테고리
- `Quote`: 캠페인·인플루언서 참조, 입력 스냅샷, 산정 결과, 상태, 유효기간
- `PricingRule`: 플랫폼·카테고리·포맷별 기준값과 보정계수, 버전, 적용일

## 9. 비기능 요구사항

- 반응형 웹: 데스크톱과 모바일 브라우저를 지원한다.
- 성능: 일반 입력값에서 계산 결과를 1초 이내에 표시한다.
- 보안: 조직별 데이터를 분리하고, 공유 링크는 추측하기 어려운 토큰을 사용하며 만료·철회할 수 있어야 한다.
- 개인정보: 공개 프로필 지표만 수집하며, 사용자가 입력한 데이터의 삭제 요청을 처리한다.
- 감사성: 견적 생성 시점의 산정 규칙 버전과 입력값을 보존한다.

## 10. 범위 및 단계

### MVP

- 수동 지표 입력 기반 계산기
- Instagram·YouTube·TikTok과 주요 콘텐츠 포맷
- 견적 저장, 공유 링크, PDF 내보내기
- 관리자용 규칙·가중치 관리

### 후속 버전

- 플랫폼 API 또는 인증된 데이터 연동
- 실제 계약·성과 데이터를 이용한 보정 모델
- 환율 및 다중 통화, 세금·수수료 계산
- 팀 승인 워크플로와 CRM 연동

## 11. 미결 결정 사항

- 초기 기준 CPM 및 카테고리별 보정계수의 데이터 출처
- 견적서 PDF의 법적 고지 및 세금 포함 여부
- 플랫폼 API 연동에 필요한 권한·비용·데이터 갱신 주기
- 무료/유료 요금제와 견적 저장 한도

# OSS기반SW프로그래밍

## 📌 Repository 소개

이 Repository는 2026년 9월부터 12월까지 진행하는 프로젝트, 과제, 수업 및 개인적인 학습 기록을 관리하기 위해 사용합니다.

사이드 프로젝트인 **「바리: 버려진 아이」**의 기획 및 개발 과정을 기록하고, 수업에서 진행하는 실습과 과제 내용을 함께 관리합니다.

또한 학기 동안 꾸준히 작업하고 기록하는 습관을 만들기 위해 GitHub를 활용하여 프로젝트, 과제 및 학습 활동을 지속적으로 기록합니다.

## 🎯 주요 목적

- **「바리: 버려진 아이」 데모 버전 제작**
- 프로젝트에서 **기획자와 개발자 역할을 수행하며 개발**
- 수업에서 진행되는 **실습 및 과제 수행과 기록**
- 프로젝트와 수업에 필요한 **개인 공부 및 학습 기록**
- 꾸준한 GitHub 활동을 통한 **지속적인 작업 습관 형성**

### 바리: 버려진 아이

- 기간: 2025년 9월 ~ 2026년 12월
- 역할: 기획자 / 개발자
- 목표: 데모 버전 제작
- 현재 상태: 진행 중

사이드 프로젝트의 기획과 개발을 함께 진행하며 게임의 핵심 시스템을 구현하고 플레이 가능한 데모 버전을 제작하는 것을 목표로 합니다.

## 📚 학기 동안 진행하는 활동

### 프로젝트

**「바리: 버려진 아이」**의 기획 및 개발을 진행합니다.

- 게임 기획 및 시스템 설계
- 필요한 기능 구현
- 프로젝트 진행 상황 기록
- 데모 버전 제작 및 테스트

### 수업

**OSS기반SW프로그래밍** 수업에서 진행하는 실습과 학습 내용을 기록합니다.

- 수업 실습
- 프로그래밍 학습
- Git / GitHub 학습
- 수업에서 작성한 문서 및 결과물

### 과제

수업에서 주어지는 과제를 수행하고 기록합니다.

- 과제 내용을 Issue로 관리
- 필요한 경우 별도의 Branch에서 작업
- 과제 결과물을 Repository에 기록

### GitHub 활동

학기 동안 꾸준히 Repository에 작업 기록을 남기는 것을 목표로 합니다.

- 프로젝트 작업
- 수업 실습
- 과제
- 공부 및 학습
- 문서 작성 및 정리

단순히 잔디를 채우기 위한 의미 없는 Commit보다는 실제 작업과 학습 내용을 기록하는 것을 우선합니다.
